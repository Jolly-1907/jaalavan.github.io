Purpose

I started this project to create a simple and effective power supply for my electronics projects.

It began as a way to test different electronics that I was repairing, then it evolved into being used for acutal projects and to test components and microcontroller setups.

Technical Details

This project was created with half the cost of a usual powersupply, with the additional bonus of being able to customize it to my needs. Such as adding a USB type c port for charging my devices, and a 5v output for powering my microcontrollers.

It uses a Boost buck converter bought for $17, an ATX PSW for $15, a couple of fuses for $5, usb c port for $10. A normal PSW would cost around $100.
